# Molino Control — versión estática

Esta carpeta contiene la versión independiente de Molino Control recuperada del proyecto anterior.

## Para GitHub
1. Crea un repositorio nuevo.
2. Sube `index.html` y `vercel.json` a la raíz.
3. No uses Vite ni `npm install`.
4. En Vercel selecciona el repositorio.
5. Framework: **Other**.
6. Build Command: **déjalo vacío**.
7. Output Directory: **.**
8. Deploy.

## Importante
Esta versión ya contiene los datos que estaban incorporados en la aplicación recuperada.
El botón de carga de Excel actualmente recibe el archivo en pantalla, pero la lectura/análisis real del Excel todavía debe conectarse en una siguiente etapa.
